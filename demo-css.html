ID、class、元素與 inline style

比對不同選擇器如何套用到相同元素。一般宣告中，HTML 標籤上的 inline style 優先於 ID、class 與元素規則；!important 會另外改變比較。

這一段同時符合元素、class、ID 與 inline style

class 範例：male

class 範例：female

元素選擇器範例：p

/* 元素 < class < ID < inline style */
:where(.cascade-demo) p { color: #667085; }
.male { color: #2563eb; }
#firstP { color: crimson; }

組合 selector 與 !important

多個 class 可以同時套用。下面兩條 .teacher 規則都有 !important，權重相同時，後寫的藍色生效。

通用 selector 與 Bootstrap 標題工具類別

通用 selector 會選取示範框裡的所有元素；Bootstrap 的 .h1 可套用標題外觀，但不會把 div 變成標題。

基本選取與屬性權重

選擇器權重常以 ID、class、元素三欄比較：inline style 和 !important 還有額外的 cascade 規則。

  • p → (0, 0, 1)
  • .male → (0, 1, 0)
  • #firstP → (1, 0, 0)

示範：先移除 inline style，重看 class 和 ID 的顏色差異。開啟瀏覽器 DevTools 的 Styles 面板可追蹤規則。

BOOTSTRAP NOTES

本頁 Bootstrap 重點

看一下互動元件的按鈕如何指向要切換的內容。

每個分頁按鈕透過 data-bs-target 對應一個 panel；Bootstrap 會更新選取狀態。保留 role、aria-controls 與 aria-selected，讓輔助技術也能辨認分頁。

<button class="nav-link" data-bs-toggle="tab"
        data-bs-target="#profile-pane" role="tab"
        aria-controls="profile-pane" aria-selected="false">
  個人資料
</button>
閱讀 Tabs 官方文件

Collapse 按鈕以 data-bs-target 指向內容的 ID；Accordion 再用同一個 data-bs-parent 管理同組面板。Modal 使用另一組觸發與關閉屬性。

<button data-bs-toggle="collapse"
        data-bs-target="#more-info">查看說明</button>
<div id="more-info" class="collapse">說明內容</div>
閱讀 Collapse 官方文件 · 閱讀 Modal 官方文件

BOOTSTRAP NOTES

本頁 Bootstrap 重點

form-label、form-control 與 form-text 組成一個有標籤、有提示的欄位；使用 for 對應欄位 id。

<label for="email" class="form-label">電子郵件</label>
<input id="email" class="form-control" type="email" required>
<div class="form-text">請輸入有效的電子郵件地址。</div>
閱讀 Bootstrap 表單欄位官方文件

form-check 包住選項；多個 Radio 共用相同的 name，使用者就只能選一個。required、minlength、pattern 是瀏覽器的 HTML 驗證屬性。

<div class="form-check">
  <input class="form-check-input" type="checkbox" id="updates">
  <label class="form-check-label" for="updates">接收更新</label>
</div>
閱讀表單驗證官方文件

BOOTSTRAP NOTES

本頁 Bootstrap 重點

打開範例，對照這一頁實際使用的 class。

container 限制內容寬度；row 與 col-lg-* 建立欄位；g-4 調整欄間距。

<div class="container">
  <div class="row g-4">
    <div class="col-lg-7">主要內容</div>
    <div class="col-lg-5">補充內容</div>
  </div>
</div>
閱讀 Bootstrap Grid 官方文件

Card 組織一段內容，Badge 表示分類，Button class 可建立主要或次要操作。

<article class="card">
  <div class="card-body">
    <span class="badge text-bg-primary">練習專案</span>
    <h3 class="card-title">作品名稱</h3>
    <a class="btn btn-outline-primary" href="#">了解更多</a>
  </div>
</article>
閱讀 Bootstrap Card 官方文件
